# 统计口径影响说明

- 确认与含暂计范围分别统计，单位数须独立去重。
- 去重、名称对照、匿名名额与职务择一会影响计数或显示，保留原始来源。
- 主分类与多标签、独立主体与集团、部门成果与全市去重总数不能混用。
- 姓名待定不等于参会待定；资料缺失不自动减确认名额。
- 重点与原高管口径分别统计；重点候选不计正式重点。
- 自定义方案应用前显示对当前批次确认、含暂计、重点、高管及问题数量的影响。实际结果由当前文件计算，不固定历史人数。
- 每次重新打开使用默认版重新计算；用户方案需要主动加载，不从上次会话或批次备份自动激活。
- 方案文本编辑不自动编译为统计逻辑；应同步修改对应执行参数。当前执行参数支持的范围外，记录为业务说明或待开发事项，不宣称已执行。
