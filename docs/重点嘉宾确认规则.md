# 重点嘉宾确认规则

版本：2026-11-23-v0.3；按用户确认方案试行。

## 一、统计分别保留

“总裁及副总裁以上”继续按原职务关键词规则统计，便于历史比较。本次扩展只调整重点嘉宾名单，不把国企总经理、创始人、主席或合伙人直接加入原高管人数，也不改变确认参会人数和单位数。

重点按实际职级、任职主体、经营范围和当前任职情况判断；关键词用于识别候选。无法确认的进入重点候选待核对，不计正式重点人数。

## 二、前置条件与排序

仅筛选状态“是”、去重后的确认嘉宾。企业全称、简称、类型／性质、嘉宾姓名、职务五项须完整。未知人选及参会状态待定、空白不纳入重点。

排序为A经榜单核验企业的高职级嘉宾、B其他企业的高职级嘉宾、C机构重点。同层级中集团负责人和中国区／大中华区一把手同层，明确的下属参会主体负责人随后；不得标作集团负责人。

世界500强仍为2025、2026并集，中国500强仍指中国民营企业500强。集团标签承接按已核定对照，原填榜单标签不能独立作为上榜证据。

## 三、实际职务规则

| 情形 | 建议纳入 | 待核对边界 |
| --- | --- | --- |
| 一般企业 | 董事长、总裁、CEO及符合条件的副职 | 任职范围不清或多主体裸职务需核实 |
| 央企、国企 | 集团／总部总经理、党委书记及相应副职；明确下属独立参会主体负责人按该主体判断 | 保留全部性质标签识别央国企，不只看主分类；部门总经理不能直接纳入 |
| 初创企业 | 创始人兼CEO等明确经营职务；核实仍参与经营决策的创始人、联合创始人 | 不凭创始人头衔推断企业初创或本人仍参与经营，纯头衔先列候选 |
| 外资企业 | 全球／集团主席；中国区、大中华区主席、总裁、总经理或整体经营负责人 | 需有外资性质或已核实榜单依据；市场、政府事务等职能负责人不等同区域一把手；裸主席先核对 |
| 专业服务、投资企业 | 主体明确的管理、执行、首席、高级合伙人 | 结合名称与行业；裸合伙人需核实决策权限与范围 |
| 商协会等机构 | 会长、理事长、主席等主要负责人 | 副职、名誉／荣誉、分会／委员会等需核实实际层级；机构重点排在企业之后 |

明确前任、卸任、离任、退休、助理、秘书或办公室岗位不按本次扩展纳入。普通部门负责人不能仅凭总经理称谓视为企业二把手。

## 四、人工核实

嘉宾详情提供独立重点筛选核实表，选择自动规则、待核对、纳入或排除，填写依据。人工纳入需确认目前参与经营／决策，明确集团、中国区或本参会主体范围，且满足五项完整、确认状态、榜单核验等门槛。部门范围或未知范围不能直接纳入；明确助理、秘书、卸任等不能覆盖。

核实仅适用于规则识别的相关职务候选，不将任意普通岗位提升为重点。人工核实绑定当时职务及单位主体／性质；变化后失效，须重新核实。恢复嘉宾原始数据清除该人工核实。结论、依据、范围和时间保存在本机批次、日志和JSON备份中。

## 五、输出与影响

正式重点Excel保留原五字段。候选与筛选依据另行导出，附层级、任职范围、识别依据、待核对原因、人工依据、邀请来源及原行号。

打开已导入批次或恢复备份时按新版重算重点，不修改原始Excel。确认人数、单位数、原高管口径保持不变；重点及候选数量随新规则和核实结论变化，不按固定目标人数配平。
